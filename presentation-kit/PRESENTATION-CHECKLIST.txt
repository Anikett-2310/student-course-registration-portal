4. VIVA QUESTIONS & INSTANT ANSWERS CHEATSHEET
--------------------------------------------------------------------------------
Q: Why did you use Tomcat 10.1 instead of Tomcat 9?
A: Tomcat 10.1 implements the modern Jakarta EE 10 specification (`jakarta.servlet.*`)
   rather than legacy `javax.servlet.*`, providing forward compatibility with
   current enterprise Java standards.

Q: How do you prevent SQL Injection?
A: All database queries in our Servlets (`LoginServlet`, `RegisterCourseServlet`,
   `AdminServlet`) strictly use JDBC `PreparedStatement` with parameterized queries
   (`?`), avoiding any dynamic string concatenation.

Q: How do you prevent students from tampering with requests when windows are closed?
A: Even if a user bypasses HTML UI controls, `RegisterCourseServlet` validates the
   current window status directly against the `registration_windows` table before
   executing any insert.

Q: How are database credentials managed?
A: In our deployment model, credentials are not hardcoded; they are injected via
   environment variables (`PORTAL_DB_URL`, `PORTAL_DB_USER`, `PORTAL_DB_PASSWORD`)
   and Tomcat JVM properties, failing safely if credentials are not provided.
